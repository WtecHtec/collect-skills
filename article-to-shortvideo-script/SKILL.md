# 文章转短视频口播文案（去AI味版）

## 目标

把"用眼睛看的书面文字"转换成"用耳朵听、强节奏、强留存"的短视频口播稿。这不只是信息重组，还要同时清除AI写作的结构性腔调——因为AI味的句子在口播场景里问题更明显：观众一听就出戏，完播率会掉。

两个任务同时完成：
1. **重构信息呈现顺序**：钩子→悬念→内容→反转→CTA
2. **清除AI腔调**：二元对比壳、伪洞察词、讲义冒号、空泛比喻结尾

## 转换前必须先确认（信息不足时主动假设并继续，不要卡住）

- 目标时长（默认1分钟：约260-320字；30秒：约130-160字）
- 目标平台风格（默认抖音/视频号：强钩子、快节奏、口语化）
- 是否需要保留原文的专业性/权威感，还是完全通俗化

## 转换流程

### 第一步：提炼核心信息，不按原文顺序讲

1. 提炼出一个核心结论 + 2-4个支撑信息点 + 一个能制造反差/悬念的素材。
2. 按"钩子→悬念/冲突→内容→反转/升华→CTA"重新排序，舍弃与核心结论无关的背景铺垫和次要论证。

### 第二步：写开头（黄金3秒钩子）

用反常识、直接提问、悬念留白或利益前置开场，不要用背景介绍或"大家好呀"式客套开场。

钩子写法也要避开AI腔——不要写成"你以为...其实..."这种二元对比壳（属于下面的硬性禁用项），改用更直接的提问或反差陈述。

### 第三步：正文改写为口语化短句，同时清除AI腔调

**口语化要求：**
- 每句尽量不超过15-18字，长句拆短句
- 数字、术语转成听得懂的说法
- 避免"如下图""见表1"这类依赖视觉的表达
- 用第二人称"你"增加对话感
- 每个信息点讲完后用一句钩子式过渡防止划走

**同时必须遵守的去AI味硬性禁用（Hard Bans）——这是本skill的核心约束，优先级和口语化要求同等重要：**

#### 1. 二元对比壳（最常见，重点排查）

禁止使用：
- `不是 A，而是 B` / `并非 A，而是 B`
- `不在于 A，而在于 B`
- `不只是 A，更是 B` / `不仅 A，还/更 B`
- `与其 A，不如 B` / `与其说 A，不如说 B`
- `不是不 A，而是 B`
- `既不是 A，也不是 B`
- `不单纯是 A，还是 B`
- `不是没有 A，而是 A 不够`

改法：直接说后半句承载的判断，不要绕。

反例（AI腔）：这条视频讲的不是省钱技巧，而是怎么避免踩坑。
改写：这条视频教你怎么避开这几个坑。

#### 2. 命令模板式开头

禁止：`别急着X，先Y`、`先别X，先Y`、`顺序别反了`、`别搞反了`、`记住这句话`

改法：直接说具体问题或现象。

反例：别急着买，先看这三点。
改写：买之前，这三点不看会吃亏。

#### 3. 伪洞察标记词

禁止：`真正`、`其实`、`本质上`、`核心在于`、`关键在于`、`说白了`、`归根结底`、`更重要的是`、`结果有点出乎意料`、`这说明`、`这背后`

改法：直接从事实或结论起句，不加提示词。

反例：更重要的是，这三个信息点你必须知道。
改写：这三个信息点，你必须知道。

#### 4. 讲义冒号腔

禁止：`我的结论是：`、`原因很简单：`、`重点是：`、`更重要的是：`

改法：用平实的句子，或者拆成两句话。口播尤其要避免冒号腔，因为冒号在听觉上没有停顿提示，容易让人跟丢。

#### 5. 空泛比喻/口号式结尾

禁止：`正确但无聊的XX`、`XX燃料`、`XX飞轮`、`时代分水岭`、`护城河`、`第一性原理`、`降维打击`、`新范式`、`新常态`

改法：结尾落在具体的行动号召或具体结果上，不要用空泛比喻收尾。

#### 6. 空泛施压/焦虑话术

禁止：`差距会突然变得很难看`、`差距会被迅速拉开`、`会成为新的分水岭`、`更值得关注的是...`

改法：说出具体、可感知的后果，而不是制造抽象焦虑。

### 第四步：控制节奏与时长

- 按目标时长换算字数（口播语速约260-320字/分钟，短视频取上限）
- 句子长短交替制造节奏感
- 原文信息量超出目标时长时，优先压缩论证过程，保留结论+反差感最强的证据

### 第五步：结尾必须有明确CTA

结尾必须包含关注/点赞/收藏引导、互动引导或悬念式下集预告之一，且不能用空泛比喻或口号收尾（见上面第5条禁用项），要落在具体的号召动作上。

### 第六步：标点与朗读格式处理（TTS/朗读友好化）

口播稿最终是给人念或给TTS工具读的，标点和英文缩写的写法会直接影响停顿和发音，必须按以下规则统一处理：

**1. 标点替换规则**

- 分号（；）→ 改为逗号（，）
- 冒号（：）→ 改为逗号（，）
- 破折号（——）→ 改为逗号（，）

这一步在全文写完后统一执行一次全文扫描替换，不要遗漏。注意这条和前面"讲义冒号腔"规则不同：讲义冒号腔是语义/结构层面的问题（抽象判断后接冒号引出讲义感），这里是标点符号层面的**逐字符强制替换**，无论语境如何，只要出现分号、冒号、破折号，一律替换为逗号。

**2. 英文缩写拆字规则**

英文单词如果不是可以正常整体读出的标准单词（即字母缩写、非自然发音的组合），需要拆开逐字母写，字母之间用空格分隔，方便TTS按字母朗读而不是拼读成一个词。

- `AI` → `A I`
- `RAG` → `R A G`
- `API` → `A P I`
- `LLM` → `L L M`
- `CTA` → `C T A`

判断标准：如果这个英文组合本身就是一个能自然拼读的单词（如 `Agent`、`Claude`、`GPT`按品牌名整体读、`app`），保留原样，不拆分；如果是纯字母缩写，且没有约定俗成的整体读法（如念作"gif"这种例外除外），必须拆开加空格。

## 输出格式

```
【钩子/开头】
（3秒内抓住注意力的一两句话）

【正文】
（按信息点分段）

【结尾/CTA】
（行动号召）

字数：约 XXX 字
预计时长：约 XX 秒
```

## 自检清单（输出前必须逐条检查）

**内容与结构：**
- [ ] 开头3秒是否有钩子，而不是背景介绍？
- [ ] 信息顺序是否按"钩子→悬念→内容→反转→CTA"重新组织？
- [ ] 是否有依赖视觉的表达残留（"如图""见表"）？
- [ ] 结尾是否有明确CTA？
- [ ] 字数是否匹配目标时长？

**语言与去AI味（逐句扫描以下字符串/结构）：**
- [ ] 是否有"不是...而是..."及其变体（不是不/与其说/既不是/不单纯是）？
- [ ] 是否有"别急着""先别""顺序别反了"等命令模板开头？
- [ ] 是否有"真正""其实""本质上""核心在于""关键在于""更重要的是"等伪洞察词？
- [ ] 是否有讲义冒号腔（抽象判断后接冒号）？
- [ ] 结尾是否用了空泛比喻或口号（"飞轮""燃料""分水岭""护城河"等）？
- [ ] 是否有空泛施压/焦虑话术而没有具体后果？

若发现以上任一项，重写该句，不要只做局部替换。

**标点与朗读格式：**
- [ ] 全文是否已无分号（；）、冒号（：）、破折号（——），是否都已替换为逗号？
- [ ] 英文缩写（AI、RAG、API、LLM等非自然拼读单词）是否已拆成大写字母+空格形式？
- [ ] 能自然整体拼读的英文词（Agent、Claude等）是否保持原样，没有被误拆？

## 示例（原文 → 最终口播文案）

**原文风格：**
"根据某机构2023年发布的调查报告显示，超过37.5%的年轻人存在睡眠拖延现象，这一现象与手机使用时长呈正相关，专家指出，睡眠拖延会导致..."

**未去AI味的口播文案（有问题）：**
"你以为熬夜是因为工作忙，其实真正的原因是手机。更重要的是，这个习惯正在悄悄拉大你和别人的差距。"
→ 问题：包含"你以为...其实..."（二元对比壳变体）、"真正"（伪洞察词）、"更重要的是"（伪洞察词）、"拉大差距"（空泛施压）。

**去AI味后的口播文案：**
"你是不是也这样，明明困得不行，还是要刷会儿手机才睡？
一项调查发现，接近四成的年轻人都有这个毛病。
刷手机时间越长，这个问题越严重。
关注我，下期讲怎么把这个习惯改掉。"

**标点与英文拆字处理示例：**

原稿（未处理）：睡前刷手机的原因很复杂——有人是习惯，有人是焦虑；用AI做的一份调研显示，超过四成年轻人存在这个问题。

处理后：睡前刷手机的原因很复杂，有人是习惯，有人是焦虑，用 A I 做的一份调研显示，超过四成年轻人存在这个问题。

## 注意事项

- 保留原文核心事实和结论，不能为了"抓人"编造或夸大信息。
- 去AI味不等于删掉所有连接词，正常的口语连接词（"所以""不过""另外"）可以保留，只禁用上面列出的具体结构和词汇。
- 原文信息量过大时，主动提示用户拆成2-3条视频，而不是硬塞。
- 不同细分平台略有差异（抖音/视频号强钩子强反转；小红书偏"闺蜜聊天感"；B站中视频可适当保留解释性内容），可按平台微调语气，但去AI味的硬性禁用项不因平台而放松。
