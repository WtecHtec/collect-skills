# 文章转视频号干货口播文案（去AI味版）

## 目标

把"用眼睛看的书面文字"转换成"用耳朵听、有信息增量、建立信任感"的视频号干货口播稿。这是干货分享场景，不是娱乐反转场景——核心目标是让观众清楚感受到"这条视频教会了我具体的东西"，而不是靠悬念反转博眼球。同时要清除AI写作的结构性腔调，因为AI味的句子在口播场景里问题更明显：观众一听就出戏，会怀疑内容的可信度。

三个任务同时完成：
1. **按架构组织内容**：价值预告→分点讲解→总结升华（不需要凑字数、也不强制加CTA，内容讲完自然收尾即可）
2. **清除AI腔调**：二元对比壳、伪洞察词、讲义冒号、空泛比喻结尾
3. **保持干货可信感**：信息密度要够，观点要有具体依据，不能为了抓人牺牲准确性

## 转换前必须先确认（信息不足时主动假设并继续，不要卡住）

- 目标平台风格（默认视频号：干货分享风格，语气可信、专业、直接，不走强反转强悬念路线）
- 是否需要保留原文的专业性/权威感，还是完全通俗化（干货类默认保留一定专业感，专业术语解释清楚即可，不必完全"降智"）

不需要预设字数或时长，按内容本身该讲多少讲多少，把架构走完整即可。

## 转换流程

### 第一步：提炼核心信息，按干货逻辑重新组织

1. 提炼出一个核心结论/方法 + 2-4个可执行的支撑信息点（观点、方法、步骤、数据均可）+ 能让人一听就知道"有用"的价值锚点。
2. 按"价值预告→分点讲解→总结/升华"重新排序，舍弃与核心结论无关的背景铺垫和次要论证。干货类不需要刻意制造反转悬念，信息本身的实用性就是留存点。

### 第二步：写开头（价值前置型钩子）

视频号干货类的开头核心任务是让观众在几秒内明确"看完这条能得到什么"，常见写法：
- 直接点明能解决的问题："这3个方法能帮你解决XX问题"
- 痛点提问后立刻给价值预告："还在为XX发愁？这条视频给你讲清楚"
- 数据/事实反差引入，但不需要刻意悬念留白："大多数人不知道，XX其实可以这样做"

不要用背景介绍或"大家好呀"式客套开场，也不要用抖音式强烈悬念留白（"这个秘密90%的人都不知道"这类过度夸张的话术），视频号观众更吃"实在、专业、直接"的调性。

钩子写法也要避开AI腔——不要写成"你以为...其实..."这种二元对比壳（属于下面的硬性禁用项），改用更直接的提问或价值陈述。

### 第三步：正文改写为口语化短句，同时清除AI腔调

**口语化要求：**
- 句子偏短、口语化，长句拆成短句，但不需要按固定字数限制卡，把一个观点讲完整、讲清楚更重要
- 数字、术语转成听得懂的说法，专业术语可以保留，但第一次出现时用一句大白话解释清楚，不要为了"降智"丢失专业性
- 避免"如下图""见表1"这类依赖视觉的表达
- 用第二人称"你"增加对话感，但语气偏向"分享经验的朋友/专业博主"，而不是"追更悬念的营销号"
- 每个信息点讲完后用一句自然过渡句衔接下一点，比如"第二个方法是""再说说XX"，不需要制造悬念钩子，清晰的逻辑推进本身就是留存点
- 分点讲解时用清晰的序数词（"第一""第二""第三"），方便观众跟上信息结构

**同时必须遵守的去AI味硬性禁用（Hard Bans）——这是本skill的核心约束，优先级和口语化要求同等重要：**

#### 1. 二元对比壳（最常见，重点排查）

禁止使用：
- `不是 A，而是 B` / `并非 A，而是 B`
- `不在于 A，而在于 B`
- `不只是 A，更是 B` / `不仅 A，还/更 B`
- `与其 A，不如 B` / `与其说 A，不如说 B`
- `不是不 A，而是 B`
- `既不是 A，也不是 B`
- `不单纯是 A，还是 B`
- `不是没有 A，而是 A 不够`

改法：直接说后半句承载的判断，不要绕。

反例（AI腔）：这条视频讲的不是省钱技巧，而是怎么避免踩坑。
改写：这条视频教你怎么避开这几个坑。

#### 2. 命令模板式开头

禁止：`别急着X，先Y`、`先别X，先Y`、`顺序别反了`、`别搞反了`、`记住这句话`

改法：直接说具体问题或现象。

反例：别急着买，先看这三点。
改写：买之前，这三点不看会吃亏。

#### 3. 伪洞察标记词

禁止：`真正`、`其实`、`本质上`、`核心在于`、`关键在于`、`说白了`、`归根结底`、`更重要的是`、`结果有点出乎意料`、`这说明`、`这背后`

改法：直接从事实或结论起句，不加提示词。

反例：更重要的是，这三个信息点你必须知道。
改写：这三个信息点，你必须知道。

#### 4. 讲义冒号腔

禁止：`我的结论是：`、`原因很简单：`、`重点是：`、`更重要的是：`

改法：用平实的句子，或者拆成两句话。口播尤其要避免冒号腔，因为冒号在听觉上没有停顿提示，容易让人跟丢。

#### 5. 空泛比喻/口号式结尾

禁止：`正确但无聊的XX`、`XX燃料`、`XX飞轮`、`时代分水岭`、`护城河`、`第一性原理`、`降维打击`、`新范式`、`新常态`

改法：结尾落在具体的行动号召或具体结果上，不要用空泛比喻收尾。

#### 6. 空泛施压/焦虑话术

禁止：`差距会突然变得很难看`、`差距会被迅速拉开`、`会成为新的分水岭`、`更值得关注的是...`

改法：说出具体、可感知的后果，而不是制造抽象焦虑。

### 第四步：结尾自然收尾，不强制CTA

内容讲完后自然收个尾即可，比如简单总结一下核心信息，或者呼应一下开头的价值预告。不需要每次都硬加"关注/点赞/转发"这类号召性结尾——如果原文或场景本身适合带一句自然的分享引导（比如确实是"我自己实测有效"这种可以顺带一句"收藏起来"），可以保留，但这不是必须项，避免为了加CTA而显得生硬。

### 第五步：标点与朗读格式处理（TTS/朗读友好化）

口播稿最终是给人念或给TTS工具读的，标点和英文缩写的写法会直接影响停顿和发音，必须按以下规则统一处理：

**1. 标点替换规则**

- 分号（；）→ 改为逗号（，）
- 冒号（：）→ 改为逗号（，）
- 破折号（——）→ 改为逗号（，）

这一步在全文写完后统一执行一次全文扫描替换，不要遗漏。注意这条和前面"讲义冒号腔"规则不同：讲义冒号腔是语义/结构层面的问题（抽象判断后接冒号引出讲义感），这里是标点符号层面的**逐字符强制替换**，无论语境如何，只要出现分号、冒号、破折号，一律替换为逗号。

**2. 英文缩写拆字规则**

英文单词如果不是可以正常整体读出的标准单词（即字母缩写、非自然发音的组合），需要拆开逐字母写，字母之间用空格分隔，方便TTS按字母朗读而不是拼读成一个词。

- `AI` → `A I`
- `RAG` → `R A G`
- `API` → `A P I`
- `LLM` → `L L M`
- `CTA` → `C T A`

判断标准：如果这个英文组合本身就是一个能自然拼读的单词（如 `Agent`、`Claude`、`GPT`按品牌名整体读、`app`），保留原样，不拆分；如果是纯字母缩写，且没有约定俗成的整体读法（如念作"gif"这种例外除外），必须拆开加空格。

## 输出格式

```
【开头】
（价值预告，点明能解决的问题）

【正文】
（按信息点分段，第一/第二/第三...）

【结尾】
（自然总结/升华，如适合可带一句轻量分享引导，非必须）
```

## 自检清单（输出前必须逐条检查）

**内容与结构：**
- [ ] 开头是否直接点明价值/能解决的问题，而不是背景介绍或客套开场？
- [ ] 信息顺序是否按"价值预告→分点讲解→总结升华"重新组织？
- [ ] 分点讲解是否用了清晰的序数词，逻辑推进是否顺畅？
- [ ] 是否有依赖视觉的表达残留（"如图""见表"）？
- [ ] 结尾是否自然，没有为了加CTA而显得生硬？
- [ ] 是否保留了必要的专业性，没有为了"抓人"而牺牲信息准确性？

**语言与去AI味（逐句扫描以下字符串/结构）：**
- [ ] 是否有"不是...而是..."及其变体（不是不/与其说/既不是/不单纯是）？
- [ ] 是否有"别急着""先别""顺序别反了"等命令模板开头？
- [ ] 是否有"真正""其实""本质上""核心在于""关键在于""更重要的是"等伪洞察词？
- [ ] 是否有讲义冒号腔（抽象判断后接冒号）？
- [ ] 结尾是否用了空泛比喻或口号（"飞轮""燃料""分水岭""护城河"等）？
- [ ] 是否有空泛施压/焦虑话术而没有具体后果？

若发现以上任一项，重写该句，不要只做局部替换。

**标点与朗读格式：**
- [ ] 全文是否已无分号（；）、冒号（：）、破折号（——），是否都已替换为逗号？
- [ ] 英文缩写（AI、RAG、API、LLM等非自然拼读单词）是否已拆成大写字母+空格形式？
- [ ] 能自然整体拼读的英文词（Agent、Claude等）是否保持原样，没有被误拆？

## 示例（原文 → 最终口播文案）

**原文风格：**
"根据某机构2023年发布的调查报告显示，超过37.5%的年轻人存在睡眠拖延现象，这一现象与手机使用时长呈正相关，专家指出，可以通过设定固定的睡前流程、减少睡前屏幕暴露、使用白噪音等方式改善睡眠拖延..."

**未去AI味的口播文案（有问题）：**
"你以为睡眠拖延是因为工作忙，其实真正的原因是手机。更重要的是，这个习惯正在悄悄拉大你和别人的差距。想解决这个问题，别急着换手机，先看看这几个方法。"
→ 问题：包含"你以为...其实..."（二元对比壳变体）、"真正"（伪洞察词）、"更重要的是"（伪洞察词）、"拉大差距"（空泛施压）、"别急着...先..."（命令模板开头）。

**去AI味后的视频号干货口播文案：**
"这3个方法，能帮你改掉睡前拖延不睡觉的毛病。
一项调查发现，接近四成的年轻人都有睡眠拖延的问题，而且和刷手机时间直接相关。
第一个方法，固定一套睡前流程，让身体形成条件反射。
第二个方法，睡前一小时尽量减少看手机的时间。
第三个方法，可以试试白噪音，帮助更快进入睡眠状态。
这几个方法说起来简单，坚持下来睡眠质量会明显不一样。"

**标点与英文拆字处理示例：**

原稿（未处理）：睡前刷手机的原因很复杂——有人是习惯，有人是焦虑；用AI做的一份调研显示，超过四成年轻人存在这个问题。

处理后：睡前刷手机的原因很复杂，有人是习惯，有人是焦虑，用 A I 做的一份调研显示，超过四成年轻人存在这个问题。

## 注意事项

- 保留原文核心事实和结论，不能为了"抓人"编造或夸大信息，干货类内容的可信度比娱乐反转更重要。
- 去AI味不等于删掉所有连接词，正常的口语连接词（"所以""不过""另外"）可以保留，只禁用上面列出的具体结构和词汇。
- 原文信息量过大时，主动提示用户拆成2-3条视频，而不是硬塞。
- 视频号干货风格的核心是"实在感"：观众看完要觉得"学到了具体东西"，而不是"被套路了"。避免过度营销号话术（如"绝对干货""看完血赚"这类夸张用词），语气可以自信但不要浮夸。
