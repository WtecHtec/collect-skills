# 标题钩子提炼

本技能输入任意文章/长文本，输出一组"主标题 + 副标题"，核心判断标准是**这个标题会不会让读者停下滑动的手指点进去看**，而不是"是否准确概括了文章内容"——两者常有冲突，本技能优先前者，但需守住"不失真"的底线，不做纯标题党式的失实夸大。

## 使用流程

1. 通读输入内容，判断文章中最吸引人/最反常识/最有信息增量的那个点(不是文章的中心论点复述，而是"读者会为之停下来"的那个钩子)
2. 按下方"钩子规则"生成候选主标题(建议产出2-3个候选，而非只给一个)
3. 生成副标题，负责补全主标题没说清楚的背景信息
4. 如果本技能的输出将用于封面图，可将结果传递给 cover-layout 技能进行排版

## 钩子规则

好的钩子标题通常具备以下至少一种特征：

- **制造认知缺口**：说出一个结论但不说原因/方法，让读者好奇"为什么"(如"90%的人排版都做错了一步")
- **反常识/反预期**：挑战读者原有认知(如"不是模板不够多，是你根本不该用模板")
- **具体数字/结果前置**：用具体可感知的数字代替模糊描述(如"4种排版，解决所有封面难题")
- **对话式提问**：直接抛出读者会问自己的问题(如"为什么你的封面总是没人点？")

## 主标题与副标题分工

- **主标题**：承担"钩子"功能，简短有冲击力，通常不超过15个字，一句话只做一件事(不要既想反常识又想堆数字)
- **副标题**：承担"补全信息"功能，交代主标题没说清楚的背景/范围，降低"标题党"感，让读者点进去后不觉得被骗

## 输出格式

```
候选主标题:
1. ...
2. ...
3. ...

推荐副标题: ...

推荐理由: (说明为什么这个组合符合钩子规则，命中了哪一种特征)
```
