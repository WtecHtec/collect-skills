# 内容发布策略

本技能覆盖内容从"素材"到"发布"的完整改写流程：筛选并选定角度、改写成文、受众校验、渠道适配，最终产出**一篇可直接发布的完整文章**，而不是分析建议或改写方案。

## 使用流程

1. **筛选并主动选角度**：不只判断"值不值得发"，而是主动从原始素材中挑出一个最强角度切入(命中"情绪共鸣"或"干货价值"至少一项)，直接决定用哪个角度写，不需要用户再拍板
2. **改写成文**：按固定人设风格，围绕选定角度直接写出完整文章正文，目标是让读者读完有"醍醐灌顶"的感觉
3. **受众校验**：改写过程中始终对照"需要情绪价值的人"这一受众画像，检查文章是否有情绪落点
4. **渠道适配输出**：根据目标发布渠道(推特/小红书)调整成文格式，输出最终版本；若用户未指定渠道，默认同时产出两个渠道的版本

## 第一步：筛选与选角度(内容雷达)

判断标准，命中以下任一类即视为"值得往下做"：

- **情绪共鸣类**：能让读者产生"这说的就是我"的代入感，触发被理解、被看见的情绪反应
- **干货价值类**：提供读者能直接拿去用的具体方法、结论或认知，读完有实际收获，不是空泛感慨

**主动选角度**：原始素材往往能从多个角度切入，本技能不把选择权丢给用户，而是主动判断——原始素材里哪一个点最有传播力(最容易引发"这说的就是我"或"这个方法我能用"的反应)，直接锁定这一个角度作为改写方向，并在输出时用一句话说明"本次选择的角度"，而不是罗列多个角度让用户自己选。

若素材完全不命中以上两类(如单纯记录性内容、无观点的流水账)，才需要如实告知用户"这段素材暂不适合改写"，而非强行选一个牵强的角度硬写。

## 第二步：改写成文(文风与人设)

改写目标：**直接、本质，让读者读完有醍醐灌顶的感觉。**

具体执行原则：
- **去除铺垫和客套**：不绕弯子，开头直接抛出核心观点，不用"最近我在想""大家好今天聊聊"这类暖场句式
- **说本质，不说表象**：把问题往下挖一层，说出表象背后的原因或规律，而不是停留在现象描述
- **语言简练、有判断力**：敢下结论，敢用肯定句式，避免"可能""或许""见仁见智"这类模糊表达冲淡观点力度
- **保留"人"的口吻**：本质化不等于说教感，仍需保留自然口语的节奏感，避免读起来像分析报告
- **直接产出完整正文**：不输出"改写思路"或"改写要点"这类分析性文字，改写的最终产物就是可以直接复制发布的文章本身

## 第三步：定位受众

目标受众画像：**需要情绪价值的人。**

这意味着改写和选题时始终要问自己：这段内容能不能让这类读者感到"被理解""被安慰""被点醒"？技术上再正确、逻辑上再严谨，如果读完让人感觉冷冰冰、没有情绪落点，就偏离了受众需求，需要重新调整表达方式(不是调整观点本身)。

## 第四步：分发渠道适配

同一份改写后的内容，发布到推特和小红书前需要做渠道适配，二者不能直接照搬同一版本：

| 维度 | 推特(X) | 小红书 |
|---|---|---|
| 篇幅 | 短，观点前置，适合单条金句或短线程(thread) | 可稍长，适合配图+正文的"图文卡片"结构 |
| 语言节奏 | 更快、更犀利，适合直接的断言句 | 可稍带一点分享感/自述语气，但核心观点仍需前置 |
| 配图 | 非必需，纯文字也可 | 通常需要配图/封面(可调用 cover-layout 技能生成) |
| 标题 | 通常无独立标题概念，首句即标题 | 需要独立的钩子标题(可调用 hook-title-extraction 技能提炼) |

## 输出格式

最终交付物结构如下，直接给出成文，不额外附加"分析过程"：

```
选定角度：[一句话说明本次改写选择的切入角度]

—— 推特版 ——
[完整正文，符合推特篇幅与节奏]

—— 小红书版 ——
标题：[钩子标题]
[完整正文，符合小红书篇幅与格式]
```

若用户已指定单一渠道，则只输出对应渠道的版本，不必两个都给。

## 与其他技能的配合

本技能通常作为整个内容流程的起点或终点使用，可与以下技能组合：

- 若发布到小红书需要配图/封面：改写完成后调用 `hook-title-extraction` 提炼小红书标题，再调用 `cover-layout` 生成封面图
- 完整链路：素材 → (本技能)筛选与改写 → hook-title-extraction(提炼标题) → cover-layout(生成封面) → (本技能)按渠道适配格式后发布
