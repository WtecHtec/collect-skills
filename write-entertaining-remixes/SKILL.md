# 克制短篇二创

## 核心目标

把一个素材写成最小但完整的内容单元。

不要机械压缩长文，也不要默认每条素材都需要一个深刻观点。先判断素材的价值来自“需要看懂的一层”，还是“值得保留的一个瞬间”，再选择路径。

### 认知路径

适合资讯、观点、变化、机制和需要少量解释的处境：

> 一个具体细节 → 翻开隐藏的一层 → 留下一个判断或余味

### 轻分享路径

适合反差、荒诞、可爱、尴尬、人物原话、视觉发现和生活瞬间：

> 一个具体细节 → 保留最有意思的关系或节奏 → 在恰好的位置停下

两条路径都保持完整、自然、克制。认知路径不要写成小论文；轻分享路径不要为了显得有深度而解释笑点。

## 识别输入

根据输入执行最小必要流程：

- 用户已经给出二创角度：直接写，不重新生成多个角度。
- 用户只给素材：先判断认知路径或轻分享路径，再提炼一个最自然的主角度。
- 用户给出长文：选择一个能够独立成立的内容单元，不做全文摘要。
- 用户给出短稿：判断它缺少细节、逻辑、节奏还是停止点，再进行改写。
- 用户指定长度：在不破坏完整性的前提下遵循。
- 用户未指定长度：选择最短的完整形式。
- 用户要求多个版本：保持同一个内容动作，按表达密度展开。

若输入来自娱乐优先选材流程，可能包含：

```text
素材：
娱乐触发点：
人的抓手：
可加入的个人观察：
事实或伦理风险：
```

接收这些字段时：

- 保留娱乐触发点，不重新把素材改造成严肃议题。
- 把人的抓手作为具体细节或关系。
- 把个人观察视为可选项，不是必须写入的结论。
- 个人观察会解释笑点、重复素材或让内容变重时，舍弃它。
- 保留必要的事实与伦理风险，不因篇幅短而省略边界。

## 第一步：确定唯一内容动作

先在内部完成一句话：

> 读者读完后，只需要多获得________。

从以下动作中只选一个：

- **看懂**：澄清一个容易误解的变化或关系。
- **修正**：补充一个条件、边界、代价或反例。
- **认出**：准确命名一种处境、矛盾或情绪。
- **看见**：让一个动作、物件、人物或画面变得可见。
- **连接**：把素材与另一段经历、作品或长期变化联系起来。
- **会心**：让读者在一个反差、停顿、错位或熟悉处境里笑一下、顿一下或认领一下。

“会心”不要求读者获得知识或接受结论。素材本身已经成立时，让它成立就够了。

如果短文同时想完成三个动作，缩小角度或拆开。

## 第二步：选择写作路径

选择认知路径，当素材满足以下任一条件：

- 不补一个条件就容易被误解。
- 具体细节背后确实存在值得说清的机制、关系或代价。
- 读者需要少量背景才能理解为什么重要。
- 内容动作是看懂、修正或连接。

选择轻分享路径，当素材满足以下任一条件：

- 原话、动作、画面或反差已经有即时反应。
- 多解释一层会削弱趣味。
- 内容动作是会心或看见。
- 素材最好的部分是顺序、停顿、措辞或画面关系。

不要因为题材严肃就自动选择认知路径，也不要因为素材好笑就忽略必要事实。选择取决于内容真正的价值所在。

## 第三步：建立最小写作卡

### 认知路径三点卡

1. **进入细节**：一个事实、句子、动作、场景、物件或反差。
2. **隐藏一层**：该细节背后的机制、条件、情绪、选择或关系。
3. **最终落点**：希望读者带走的判断、感受、画面或问题。

三项之间必须自然推进。不要用口号连接逻辑断点。

### 轻分享三点卡

1. **娱乐触发点**：究竟是哪句话、动作、画面或错位让素材成立。
2. **必要铺垫**：读者理解触发点所需的最少背景。
3. **停止点**：在哪一句之后继续解释就会变差。

轻分享允许没有显性的“隐藏一层”和“最终结论”。停止点本身就是结构的一部分。

## 第四步：选择短篇形态

### 短判断

结构：事实或原话 → 必要条件 → 克制结论。

适合资讯、产品、职场、争议观点和现实选择。

### 短观察

结构：具体细节 → 一处连接 → 留下值得注意的一层。

适合社会、设计、生活、趋势和日常发现。

### 短共鸣

结构：具体场景 → 被忽略的感受 → 准确命名或留白。

适合人物经历、创作、关系和个人成长。

### 短画面

结构：一个物件或动作 → 它承载的变化 → 画面式结束。

适合摄影、电影、音乐、设计、人物和情绪内容。

### 轻分享

结构：必要铺垫 → 原话、动作或反差 → 及时停止。

适合荒诞日常、温柔细节、人物片段、视觉发现、轻知识和自然笑点。可以加入一句个人观察，但不能抢走素材本身的位置。

## 第五步：选择表达密度

根据内容需要选择形式，不根据发布平台选择。

### 一句话

默认长度：30～80 个中文字。

只保留一个已经成立的观察、判断、画面或反差。轻分享素材在无需背景时优先使用这一档。

### 微短文

默认长度：80～180 个中文字。

使用一个自然段，必要时分为两个短段。适合需要少量铺垫、逻辑铰链或人物关系的素材。

### 小短文

默认长度：180～500 个中文字。

使用两至四个自然段。允许增加一个过程、对比或例子，但不得发展出第二主角度。

娱乐素材只有在故事过程本身有价值时才选择小短文。不要为达到字数，把一个一句话笑点扩写成解释性文章。

长度是编辑预算，不是硬性字符上限。能够更短说清时，不为凑字数扩写。

## 第六步：写出最短完整版本

### 认知路径

1. 直接呈现具体细节，不写泛泛背景。
2. 只翻开一层，不罗列全部分析。
3. 完成唯一内容动作，不重复总结。

### 轻分享路径

1. 把最有意思的事实、原话或画面放在清楚的位置。
2. 只补理解它所需的最少背景。
3. 保留原素材的顺序、停顿或反差，不提前解释结果。
4. 最多加入一句个人观察。
5. 到达停止点后立即结束。

轻分享可以有节奏，但不要使用机械的一词一行。可以干一点、淡一点，但不要主动添加“笑死”“太绝了”“谁懂”等情绪标签替读者反应。

## 第七步：执行减法

所有短篇按以下顺序删除：

1. 与唯一内容动作无关的背景
2. 第二个和第三个观点
3. 重复解释同一件事的句子
4. 不能推进内容的案例
5. “我觉得”“值得注意”“这意味着”等标签词
6. 为了显得完整而添加的总结
7. 删除后不影响内容的形容词和连接词

轻分享额外删除：

- 对笑点、反差或温柔细节的解释
- 强行上升出的社会意义和人生道理
- 诱导互动的空泛问题
- 把读者应该感到什么直接说出来的句子
- 素材已经表达过的个人观察

不要删除具体细节、事实归属、必要限定、逻辑铰链或真正的停止点。

## 第八步：生成不同密度版本

用户要求多个版本时，共享同一个具体细节、内容动作和停止点：

- 一句话版只留下最集中的观察、画面或反差。
- 微短文版补回必要铺垫或逻辑铰链。
- 小短文版增加一个具体过程、例子或人的处境。

更长版本不得增加第二观点。轻分享的更长版本也不能变成解释笑点的文章；没有新增过程可写时，宁可说明不适合继续扩展。

## 事实与来源

- 原作者说法使用自然归属，不把转述写成自己的发现。
- 产品发布、数据、日期和人物身份优先核验原始来源。
- 图片、视频和个人经历保留出处与必要上下文。
- 不确定性来自证据不足时明确说明，不用模糊语气掩盖。
- 不利用普通人的尴尬、疾病、灾难、未成年人或私人信息制造娱乐。
- 短篇不能因为篇幅有限而把一方口径写成公认事实。

## 风格护栏

- 使用完整中文句子与自然段落。
- 不把一句完整逻辑拆成多个单词行。
- 不使用连续排比、整齐对仗和密集反问制造节奏。
- “不是 A，而是 B”最多偶尔使用一次。
- 不用“值得注意的是”“有趣的是”“这意味着”预告观点。
- 不靠“我觉得”制造个人性；让选择的细节和停止点体现风格。
- 不把克制理解为没有态度，也不把娱乐理解为夸张语气。
- 不要求每篇内容提供建议、教程、问题或宏大意义。
- 不模仿平台黑话、引流句、热门标题或标签堆砌。
- 允许干净的冷幽默、轻微反讽和自然闲笔，但不羞辱具体的人。

## 失败诊断

- **像长文摘要**：放弃全文覆盖，只选择一个独立单元。
- **文字很短但没说完**：补回必要细节或逻辑铰链。
- **像口号或金句**：增加事实、动作或具体场景。
- **观点过多**：保留最接近最初反应的一条。
- **好笑素材被写成议论文**：切换轻分享路径，删除隐藏机制与宏大结论。
- **正在解释笑点**：保留触发点与最少铺垫，在读者已经理解处停止。
- **为了显得有趣而用力过猛**：删除情绪标签、网络黑话和夸张形容词。
- **轻分享像搬运**：只补一句真正属于自己的观察；没有增量时保留清楚归属，或不写。
- **多个密度只是重复扩写**：更长版本增加过程，不增加道理。
- **内容偏技术**：落到人的使用、选择、感受或具体后果。
- **为了短而语气生硬**：恢复自然语序，必要时选择更长一档。

## 输出格式

默认只输出可直接使用的成稿。内容动作、写作路径、三点卡、字数与事实检查都在内部完成，不主动展示。

### 单一短篇

只输出正文。用户明确要求时，再附形态、密度、字数或一句编辑说明。

### 密度阶梯

按需要输出：

1. 一句话版
2. 微短文版
3. 小短文版

只用密度名称区分，不添加平台名称。若某一档会迫使内容重复或过度解释，可以省略该档并简短说明。

### 长文切片

先列出 2～4 个能够独立成立的短篇单元。每个单元只完成一个内容动作。用户只要求一个版本时，推荐最有独立价值的一条。

必要的事实风险放在正文之后单独简短提示，不把编辑说明混进可使用正文。

## 最终自检

交付前确认：

- 是否只完成一个认知、情绪或会心动作？
- 是否选择了正确的认知路径或轻分享路径？
- 认知路径是否只翻开一层？
- 轻分享是否保住娱乐触发点，没有解释笑点？
- 是否包含足够具体的细节，并能独立理解？
- 个人观察是否提供增量，而不是抢走素材？
- 是否使用完整自然段落，没有机械断句？
- 是否保留必要事实归属和伦理边界？
- 长度是否由表达密度决定，而非平台模板？
- 结尾是否在恰好的位置停止，没有重复总结或强行升华？

用一句话概括本技能：

> 该说清的说清，该停下的及时停下。
